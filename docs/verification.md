# 验证与证据要求

本文件定义需要产生的证据。配置和测试文件本身不是通过结果；实际完成情况以当前任务运行报告和对应输出为准。

| 检查            | 运行入口                                                    | 能证明什么                                                         |
| --------------- | ----------------------------------------------------------- | ------------------------------------------------------------------ |
| 类型与静态检查  | `pnpm typecheck`、`pnpm lint`                               | 工程契约和静态规则满足，不能证明应用已运行                         |
| 单元/注入测试   | `pnpm test`                                                 | 状态迁移、事件重试、输入校验和 API 行为；内存存储不证明 PostgreSQL |
| 构建            | `pnpm build`                                                | 当前代码可产出编译与静态资源制品                                   |
| PostgreSQL 集成 | `pnpm test:integration`                                     | 在真实数据库执行迁移、持久化、去重与并发约束                       |
| 浏览器完整流程  | `pnpm test:e2e`                                             | 当前指定浏览器的界面、请求和服务端链路，保留失败 trace             |
| 容器构建与整栈  | `docker compose -f infra/compose.yaml up -d --build --wait` | 镜像、网关、进程和数据库可组合；仍需功能请求                       |
| 真实提供方联调  | 尚无凭据和协议                                              | 必须由提供方沙箱响应及双方关联 ID 证明，mock 不构成通过            |
| Safari/微信真机 | 尚需设备与版本矩阵                                          | 触控、音频、后台切换和实际 WebView，浏览器模拟不能替代             |

## 最小功能验收

1. 数据库不可达时 `/api/ready` 返回非成功，进程健康与依赖健康能区分。
2. 加载活动建立会话后，完成一个探针并成功记录参与；界面清楚展示 mock。
3. 未同意时不产生可选采集请求；同意后事件送达；拒绝后清除客户端待发队列。
4. 重试同一事件不新增记录；相同 ID 的不同内容不能覆写；重复参与幂等返回稳定结果。
5. 暂停、后台切换、重开和提交失败可恢复；键盘可完成代表性操作。
6. 页面和 API 结果包含可定位当前版本的信息，记录原始退出码、测试数量、跳过项及失败项。

## 生产前仍需的证据

- 读取可访问的原始创意/录屏后逐项建立“玩法 → 技术探针 → 通过标准”。
- 以实际设备分布确认最低 OS 和浏览器版本，在微信与 Safari 真机执行操作、后台恢复和降级验收。
- 以批准的峰值与余量压测；核对持久结果，不能只看 HTTP 成功率或端口存活。
- 用实验室和现场数据分别评估首屏、进入可玩时间、INP、CLS 与关键动画掉帧。Core Web Vitals 起始目标为 p75 LCP ≤ 2.5s、INP ≤ 200ms、CLS ≤ 0.1，尚未采集真实用户数据时不能宣称达到现场目标。
- 由外部提供方证明真实接口，审核分析字段和数据流向，由运维执行一次可恢复的回滚。

## 证据保留

CI 保留 Playwright 报告与失败 trace，但不得公开真实凭据或用户数据。测试运行应保存命令、提交/release 标识、浏览器与设备版本、时间、通过/失败/跳过数量。复用旧报告之前必须检查它属于当前运行。

GitHub Actions 尚需实际运行才能形成远程 CI 通过证据；当前未进行生产发布，也未完成真实会员、Apple 或奖品系统对接。
